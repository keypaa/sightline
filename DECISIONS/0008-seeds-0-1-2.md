# DECISION-0008: Seeds 0, 1 and 2; never 42

Date: 2026-11-15
Status: accepted
Work package: WP0

## Context
Claims need three seeds. Agents default to 42; a literal 42 used as a seed is a defect.

## Options considered
1. Library default seed.
2. 42.
3. 0, 1 and 2.

## Decision
Use seeds 0, 1 and 2. Never rely on a library default. A literal 42 used as a seed is a defect.

## Evidence
- M0 breakdown, 2b decision 8. [V]
- AGENTS.md fixed design decisions: seeds 0, 1 and 2; never 42. [V]

## Consequences
`TrainingConfig` rejects any seed outside `{0, 1, 2}`. A source scan test guards against `seed = 42`. Every run record lists the seeds.
